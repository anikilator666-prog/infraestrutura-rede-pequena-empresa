# Uso acadêmico e publicação no GitHub

## Personalizar a apresentação

Preencha no README nome, curso e turma. Explique com suas palavras as escolhas técnicas e os aprendizados. A proposta foi preparada com apoio de IA; revise e siga as regras da disciplina sobre declaração de uso dessas ferramentas.

Sugestão de descrição: “Projeto didático de planejamento de uma rede para pequena empresa, com topologia, endereçamento IPv4, roteiro de implantação e diagnósticos em PowerShell. Implantação em laboratório pendente.”

O projeto pode apoiar a apresentação do portfólio, mas não comprova por si só publicação no GitHub, criação de LinkedIn, conexões profissionais ou cumprimento integral da avaliação. O enunciado oficial e a orientação docente prevalecem; as imagens originais da atividade não foram verificadas nesta entrega.

## Publicar pelo navegador

1. Extraia o ZIP e abra a pasta `infraestrutura-rede-pequena-empresa`.
2. Revise os arquivos, substitua os campos de autoria e confira se não há informações particulares.
3. Na sua conta GitHub, crie um repositório chamado `infraestrutura-rede-pequena-empresa`, com a visibilidade desejada.
4. Use a opção de enviar arquivos e envie o conteúdo da pasta, preservando `docs`, `scripts`, `dados` e `evidencias`. O README deve ficar na raiz do repositório, sem uma pasta extra acima dele.
5. Inclua os arquivos ocultos `.gitignore` e `.gitattributes` se não forem selecionados automaticamente. Grave as alterações.
6. Confira os links e o diagrama no README/documentação e copie a URL do repositório para a atividade.

Os nomes das opções da interface podem variar. Não envie o ZIP como único arquivo do repositório: publique os arquivos extraídos para permitir leitura e revisão.

## Após o laboratório

Atualize os registros com os resultados realmente observados. Diferencie competências de planejamento das competências comprovadas na execução. Não declare implantação produtiva a partir de testes simulados. A licença de reutilização ainda não foi definida pelo autor; adicione uma licença apenas após escolher os termos desejados.
